# MVP 범위 및 도메인 규칙

## 1. 팀·리그 구조
- 우리 팀 경기만 기록한다.
- 상대 팀은 팀 이름만 저장한다. (상대 선수 기록은 저장하지 않음)

## 2. 이닝 규칙
- 정규 이닝은 9이닝이다.
- 동점일 경우 연장전은 최대 12회까지 진행할 수 있다.
- 입력 화면은 기본 9이닝을 표시하며, 조기 종료 시 진행되지 않은 이닝을 삭제할 수 있다.
- 미진행 이닝을 삭제하면 마지막 이닝을 해당 경기의 실제 종료 이닝으로 저장한다.
- ERA 등 이닝 기반 지표는 9이닝 기준으로 계산한다.

## 3. 사용자 역할
| 역할 | 권한 |
|---|---|
| 감독 | 팀 관리, 멤버 관리, 모든 경기 기록 조회·입력·수정, 경기 확정 |
| 일반 회원 | 경기 기록 조회, 본인 기록만 입력·수정 |

## 4. 기록 입력 규칙
- 우리 팀 공격 타석은 해당 타자 본인이 입력한다.
- 우리 팀 수비 타석(상대 타자 결과)은 해당 투수 본인이 입력한다.
- 타점·득점 등 다른 선수에게 영향을 주는 기록은 입력 시 관련 선수 기록에 함께 반영된다.
- 감독은 누락되거나 잘못된 기록을 직접 입력·수정할 수 있다.

## 5. 기록 관리 규칙
- 모든 기록의 생성·수정 이력(수정자, 수정 시각)을 저장한다.
- 경기 확정 전 감독이 이닝별 아웃 수와 득점 합계를 검토한다.
- 감독이 경기를 확정하면 해당 경기 기록은 수정할 수 없다.
