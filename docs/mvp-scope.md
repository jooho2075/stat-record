# MVP 범위 및 도메인 규칙

## 1. 팀·리그 구조
- 우리 팀 경기만 기록한다.
- 상대 팀은 팀 이름만 저장한다. (상대 선수 기록은 저장하지 않음)

## 2. 이닝 규칙
- 정규 이닝은 9이닝이다.
- 동점일 경우 연장전은 최대 12회까지 진행할 수 있다.
- 입력 화면은 기본 9이닝을 표시하며, 조기 종료 시 진행되지 않은 이닝을 삭제할 수 있다.
- 미진행 이닝을 삭제하면 마지막 이닝을 해당 경기의 실제 종료 이닝으로 저장한다.
- ERA 등 이닝 기반 지표는 9이닝 기준으로 계산한다.

## 3. 사용자 역할
| 역할 | 입력 | 조회 | 확정 |
|---|---|---|---|
| 감독 | 경기 정보 + 모든 선수 기록 | 팀 전체 기록 | 본인 기록 확정, 모든 선수 기록 확정 해제 |
| 일반 회원 | 본인 기록만 | 팀 전체 기록 | 본인 기록 확정 |

- 팀원들은 서로의 기록을 조회할 수 있다.

## 4. 기록 입력 규칙
- 우리 팀 공격 타석은 해당 타자 본인이 입력한다. (타석 결과, 타점)
- 우리 팀 수비 타석(상대 타자 결과)은 해당 투수 본인이 입력한다. (결과, 아웃 수, 실점, 자책점)
- 득점은 득점한 주자 본인이 "어느 타석에서 득점했는지"를 선택해 입력한다.
- 도루·도루실패는 해당 주자 본인이 입력한다.
- 따라서 한 선수의 입력이 다른 선수의 기록을 변경하는 경우는 없다.
- 감독은 모든 선수의 기록을 입력·수정할 수 있다.
- 경기 화면에서 타점 합계와 득점 합계가 다르면 경고를 표시한다.
  (실책·폭투 등으로 타점 없는 득점이 있을 수 있으므로 확인용 경고로만 사용)

## 5. 기록 확정 규칙
- 선수는 경기별로 본인 기록을 확정한다.
- 확정된 기록은 선수 본인도 수정할 수 없다.
- 감독은 확정을 해제할 수 있으며, 해제 후 감독 또는 해당 선수가 수정한 뒤 다시 확정한다.

## 6. 기록 관리 규칙
- 모든 기록의 생성·수정·확정·확정 해제 이력(수행자, 시각, 변경 전·후 값)을 저장한다.
- 경기 상태는 "진행 중 / 종료"로 관리하며, 기록 수정 가능 여부는 선수별 확정 여부로 판단한다.

## 7. MVP 제외 범위
- 견제사 등 타석 밖에서 발생하는 아웃
- 상대 팀 선수 기록
- 수비 기록
